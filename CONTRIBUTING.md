# Руководство по разработке DockDash

Мы приветствуем вклад в развитие терминального дашборда для Docker!

## Требования к окружению:
- Go 1.22+
- Установленный и запущенный Docker Daemon (локально или через сокет `/var/run/docker.sock` / `npipe:////./pipe/docker_engine`).
- Терминал с поддержкой ANSI/TrueColor.

## Проверка перед отправкой Pull Request:
```bash
# Запуск тестов
go test ./...

# Проверка форматирования
gofmt -w .
```

## Как внести вклад:
1. Создайте ветку `feature/ваша-фича`.
2. Убедитесь, что дашборд корректно отображает метрики контейнеров.
3. Откройте Pull Request с описанием изменений.
